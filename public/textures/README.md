# Iridescence lookup

`iridescence-lookup.png` is the unmodified 64×128 RGBA lookup distributed by
[Destiny Collada Generator](https://github.com/TiredHobgoblin/Destiny-Collada-Generator/blob/b5e57d106d133b46a731c2be3a9312e270e5e1e4/Resources/Iridescence%20Lookup.png),
retrieved 2026-09-29. Bungie owns the Destiny artwork; the reference project
provides the shader reconstruction and lookup. It is reference data, not a
claim that every current game palette has been extracted. PNG rows are top-down
(row zero is palette ID zero); alpha is independent material data.
